# 篆书工具 · 古文字创作玩具

三个**单文件网页**，双击就能用。字体全部内嵌（小篆 + 甲骨文），不用装任何东西。

| 页面 | 做什么 |
|---|---|
| `篆书卡片.html` | 输入名字 → 出一张篆书卡片 |
| `篆书抽象画.html`（墨象） | 输入 1 到 4 字 + 选心境 → 生成抽象画（1080×1350） |
| `古文字表情包.html`（字的表情） | 输入词 + 选语气 → 生成方形表情包（900×900） |

三个页面都是同一个操作顺序：**① 输入文字 → ② 选风格 → ③ 选排版 → ④ 选墨色 → ⑤ 保存**

---

## 墨象的六种心境

| 心境 | 参考 |
|---|---|
| 静 | Brice Marden《Cold Mountain》 |
| 烈 | 井上有一 |
| 郁 | Jackson Pollock |
| 逸 | 东巴文（纳西族象形文字） |
| 空 | Mark Rothko |
| 狂 | 当代书象（浓墨大字 + 洋红色带） |

字形与画面都是 canvas 当场算出来的，不是套模板，所以「换一张」每次都不一样。

## 表情包的六种语气

开心（撒星星）/ 无语（汗滴 + 飘线）/ 加油（火苗）/ 震惊（放射线）/ 爱心（心形）/ 墨签（宣纸 + 朱印）。

## 共用的三件事

- **最多 8 个字**，字多了自动分列 / 分行，不会挤
- **排版可选**：横排 / 竖排 / 随机
- **字形可切**：小篆（13,285 个篆形）/ 甲骨文（1,425 个汉字）
- **墨色八选**：墨、朱砂、靛青、石绿、赭石、紫、金、黛
- **字号自适应**：二分搜索求最大可容纳字号，单字不顶格、多字不挤

## 甲骨文的覆盖情况（重要）

甲骨文已释读的字有限，本字体**只有 1,425 个汉字**有对应字形：

| 范围 | 可对照 | 覆盖率 |
|---|---|---|
| GB2312 一级字（常用 3755） | 670 | 17.8% |
| GB2312 二级字（次常用 3008） | 195 | 6.5% |
| GB2312 全集（6763） | 865 | 12.8% |

全部可对照的字见 **[`甲骨文对照表.md`](甲骨文对照表.md)**。

页面在切到甲骨文时会**明确提示**哪些字缺字形（例如「你、他、是、的、焕、欢」都没有），
不会静默变样。想试甲骨文，用「日月山水」「上下大小」「人天火木」这类字。

## 打印甲骨文

本仓库附带小篆与甲骨文的对照关系；若要在 Word / Pages 里直接打甲骨文，

本仓库只内嵌了网页用得到的子集（BMP 码位，0.62 MB）。
